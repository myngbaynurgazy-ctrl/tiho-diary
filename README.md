# «Тихо» — дневник атмосферы

«Тихо» помогает сохранить не только события дня, но и его ощущение. Пользователь пишет короткую историю, выбирает настроение, добавляет кадр и песню. Из этого собирается визуальное воспоминание, которое можно открыть в архиве.

## Как ввод влияет на образ

- Настроение выбирает цветовую атмосферу дня.
- Ключевые слова в истории определяют мотив — например, воду, дорогу, свет или дом — и меняют фактуру изображения.
- Фотография становится обложкой; остальные снимки остаются в галерее записи.
- Название и ссылка на песню сохраняются вместе с записью. Добавленный аудиофайл можно прослушать; движение волн реагирует на курсор и касание.
- Общие дата, типографика и композиция связывают разные дни в одну ленту.

Это художественная система прототипа, а не психологический анализ человека.

## Художественные приёмы

- Рассеянный свет, мягкие градиенты и цветовые отражения; общий подход вдохновлён живописью Клода Моне.
- Слоистые волны, мелкое зерно и отклик графики на движение указателя или касание.
- Контрастные пятна и переменный ритм линий, отсылающие к абстрактной композиции Василия Кандинского.
- Редакционная подача: антиква в заголовках, дата, подпись поверх кадра и повторяющаяся музыкальная строка.

Референсы задают художественные принципы, но конкретные работы не копируются.

## Примеры дней

В пустом архиве показываются три демонстрационные истории с иллюстрациями, настроениями и песнями. Они не сохраняются в личные записи. Подробное описание находится в [DEMO_DAYS.md](DEMO_DAYS.md); ещё пять сюжетных вариантов — в [EXAMPLES.md](EXAMPLES.md).

## Запуск и файлы

Для полной локальной версии нужен Node.js 18 или новее. В папке проекта выполните `npm run dev` и откройте <http://localhost:3000/>. Сервер использует только встроенные модули Node.js. Данные локальных аккаунтов сохраняются в `data/`, эта папка исключена из Git.

Для быстрого просмотра можно открыть `art.html` напрямую. В таком режиме записи гостя остаются в `localStorage` текущего браузера; поиск песен и серверный вход работают только через локальный сервер. GitHub Pages также публикует статическую версию, где архив хранится в браузере.

- `art.html` и `index.html` — страница дневника и переход на неё.
- `art.css` — темы, адаптивная компоновка и визуальные состояния.
- `art.js` — записи, архив, настроение и сборка визуального образа.
- `grain-backdrop.js`, `circuit-flash.js`, `waveform-player.js`, `music-library.js` — фоновые волны, поле архива, аудиоволна и поиск/хранение музыки.
- `examples/` — три иллюстрации для демо-дней.
- `server.js` и `package.json` — локальный API и команда запуска.

`components.json` содержит адреса реестров React Bits Pro. Сам дневник остаётся приложением на HTML/CSS/JavaScript и не импортирует React-компоненты; для установки `Grain Mass` понадобится отдельный React-проект и ключ лицензии в `REACTBITS_LICENSE_KEY`.

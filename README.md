# Тихо — дневник атмосферы

## Коротко о проекте

«Тихо» превращает рассказ о прожитом дне, фотографию и песню в личное визуальное воспоминание. Пользователь описывает детали дня и выбирает настроение; интерфейс собирает из них карточку, которую можно открыть позже в архиве. Проект предназначен для тех, кому мало сухой ленты фотографий и хочется сохранить атмосферу момента.

## Как вход влияет на результат

- Настроение выбирает одну из пяти оливково-зелёных палитр и её световые оттенки.
- Рассказ становится подписью; его длина и слова, связанные с темпом, меняют движение волн и геометрию композиции.
- Первая фотография становится обложкой, остальные — галереей дня.
- Название песни показывается в музыкальной строке; ссылка на сервис открывается из воспоминания. Энергичные слова в записи или песне меняют ритм графики.
- Дата, журнальная рамка и шрифтовая пара остаются общими для всех карточек, поэтому лента выглядит цельной.

Это художественные правила прототипа, а не психологический анализ человека.

## Художественные приёмы и референсы

- **Свет и цветовые поля:** мягкие градиенты и отражения передают рассеянный свет; приём вдохновлён работами Клода Моне, но не копирует конкретные картины.
- **Живые линии:** Canvas рисует волны, которые колышутся и отклоняются вслед за касанием или курсором. Это связывает настроение записи с движением интерфейса.
- **Ритм композиции:** спокойные слова сохраняют плавный рисунок; слова о спешке, дедлайне и быстром темпе включают более резкие диагонали. Контраст и напряжение композиции отсылают к абстрактной графике Василия Кандинского.
- **Редакционная подача:** дата, крупная антиква, подпись поверх фотографии и отдельная музыкальная строка повторяются в каждом воспоминании.

Референсы используются как источники художественных принципов — света, ритма и композиции, а не как образцы для копирования.

## Код и инструменты

- `art.html` — разметка интерфейса.
- `index.html` — та же главная страница; GitHub Pages открывает её по адресу сайта автоматически.
- `art.css` — оформление, тёмная тема и адаптивная компоновка.
- `art.js` — логика карточек и архива, сжатие фото, Canvas-анимация волн, хранение в `localStorage`.
- Стек: HTML, CSS, чистый JavaScript и браузерные API. Внешние библиотеки и AI-модели в прототипе не используются. Шрифты DM Sans и Playfair Display загружаются из Google Fonts.

Откройте `art.html` в браузере. Для локального запуска сборка и сервер не нужны; интернет требуется только для веб-шрифтов. Записи хранятся в локальном хранилище этого браузера.

Для GitHub Pages достаточно поместить `index.html`, `art.css` и `art.js` в корень репозитория и включить Pages для ветки `main` и папки `/ (root)`.
